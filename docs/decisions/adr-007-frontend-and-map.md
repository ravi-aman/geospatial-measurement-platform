# ADR-007: Vite SPA + MapLibre GL JS on PostGIS vector tiles

**Status:** Accepted

## Context
The UI must upload files, follow processing, and explore results that may contain hundreds of thousands of features
— in a table and on a map. It has no SEO needs and no server-side data that the browser cannot fetch from the API.

## Decision
* **Vite + React + TypeScript single-page app**, deployable as static files (S3 + CloudFront, or the nginx image).
* **TanStack Query** for server state (status polling with `refetchInterval`, infinite queries mapped onto the API's
  keyset cursors), **TanStack Virtual** for the table (only visible rows are in the DOM).
* **MapLibre GL JS** rendering **Mapbox Vector Tiles generated by PostGIS** (`/api/files/{id}/tiles/{z}/{x}/{y}.mvt`).
* **shadcn/ui** (Radix primitives) for accessible controls, restyled to the project's visual system.

## Alternatives considered
| Option | Assessment |
|---|---|
| Next.js | SSR/RSC add a Node runtime and deployment surface with no benefit for an authenticated-style data tool; a static SPA is simpler and cheaper to host. |
| Leaflet | Excellent for small GeoJSON overlays; DOM/Canvas rendering struggles beyond ~10⁴ features and vector tiles need plugins. |
| OpenLayers | Very capable (MVT, projections); heavier API, and WebGL vector rendering is less central than in MapLibre. |
| GeoJSON for the whole file | Simple, but a 1M-feature file would mean hundreds of MB in the browser. |
| deck.gl | Great for millions of points; overkill here and adds a second rendering stack. |

## Why MapLibre + MVT
* GPU rendering; vector tiles are its native format.
* The browser only receives the features visible at the current zoom, already clipped and quantised by
  `ST_AsMVTGeom`; tiny features disappear at low zoom; tiles of finished jobs are cacheable (`Cache-Control`, `ETag`).
* Table filters are mirrored as MapLibre layer filters on tile properties — no re-fetch.
* Open source (BSD), no API key; basemap from OpenFreeMap (configurable).

## Trade-offs / consequences
* MapLibre is the largest dependency (~800 kB); the file page is lazy-loaded, keeping the initial bundle at 452 kB.
* MapLibre 6 loads its tile worker relative to its module URL, which Vite's dependency pre-bundling breaks; a small
  Vite plugin serves the worker verbatim (found and fixed during browser testing).
* The map is embedded in a scrolling page → `cooperativeGestures` (Ctrl/⌘ + scroll to zoom).
