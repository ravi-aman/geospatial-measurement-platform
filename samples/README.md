# Sample datasets

Synthetic files for trying the upload flow. All geometries, names and attributes are invented (fictional sites near
Raipur and New Delhi); no third-party or private data. Generated by `backend/scripts/generate_samples.py`.

| File | CRS | Contents | Expected result |
|---|---|---|---|
| `kml/mine_site_survey.kml` | WGS 84 (KML) | 13 placemarks in 4 folders: polygons (one with a hole, one self-intersecting), a multi-polygon, lines, a multi-line, 3 points with elevation, a point+line collection, one placemark without geometry | `COMPLETED_WITH_ERRORS`: 8 measured, 3 not applicable, 1 unsupported, 1 failed (`GEOMETRY_MISSING`); warnings `Z_COORDINATES_IGNORED`, `UNSUPPORTED_FEATURES` |
| `kml/parcel_block_wgs84.kml` | WGS 84 (KML) | 12 parcels in a grid | `COMPLETED`, each about 8,671 m² |
| `shapefile/plots_utm43n.zip` | EPSG:32643 | 6 plots | `COMPLETED`, 13,006.72 m² each |
| `shapefile/plots_web_mercator.zip` | EPSG:3857 | the same 6 plots | `COMPLETED`, 13,006.72 m² each (not the ~30 % larger Mercator area) |
| `shapefile/plots_no_prj.zip` | none (`.prj` removed) | the same 6 plots in UTM coordinates | `COMPLETED_WITH_ERRORS`, warning `CRS_MISSING`, all 6 `FAILED` with `CRS_MISSING`. Upload with `crs=EPSG:32643` to get `COMPLETED`, 13,006.72 m² each |
| `shapefile/roads_wgs84.zip` | EPSG:4326 | 3 roads, stored in an `export/` folder inside the ZIP | `COMPLETED`: 4,701.94 m, 691.88 m, 606.93 m |
| `shapefile/borewells_points.zip` | EPSG:4326 | 4 wells | `COMPLETED`, all `NOT_APPLICABLE` (points have no area or length) |
| `shapefile/parcels_edge_cases.zip` | EPSG:4326 | multipart parcel, self-intersecting parcel, empty record | `COMPLETED_WITH_ERRORS`: 2 measured (one `GEOMETRY_REPAIRED`), 1 `FAILED` (`GEOMETRY_MISSING`) |

Try one from `backend/` with the API running:

```bash
curl -s -H "Prefer: wait=10" -F file=@../samples/shapefile/plots_no_prj.zip -F crs=EPSG:32643 \
     http://localhost:8000/api/files/
```

Or drop a file onto the upload panel of the web UI.

Regenerate (rewrites `kml/` and `shapefile/`; needs the backend dev extras):

```bash
cd backend
python scripts/generate_samples.py
```

Per-feature expected values and what each file demonstrates: [docs/testing/test-data.md](../docs/testing/test-data.md).
